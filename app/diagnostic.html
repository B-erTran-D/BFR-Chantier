2. Manifeste servi par le site

Lecture…

L'identifiant (id) est ce qui distingue cette application d'une autre installée depuis le même domaine. Il doit être unique.

3. Invite d'installation

en attente…

Chrome n'affiche l'invite que s'il considère l'application comme non installée. Patientez quelques secondes.

4. Ce que Chrome croit installé

Lecture…

Si Chrome annonce « cette application est déjà installée » alors qu'aucune application BFR Chantier ne figure dans les applications du téléphone, l'enregistrement d'installation est périmé : il pointe vers une application qui n'existe plus. Le remède est de changer l'identifiant (id) du manifeste — voir PUBLIER-SUR-GITHUB.md (§ 7).

5. Hors connexion (service worker)

Lecture…

Si Chrome répond « application déjà installée » puis « impossible d'ouvrir l'application »

Ce n'est pas un défaut de l'application : Chrome garde un enregistrement d'installation périmé et tente d'ouvrir une application qui n'existe plus sur le téléphone. Dans l'ordre :

  1. Regardez la carte 4 ci-dessus : si Chrome voit une application installée alors qu'aucune n'existe, c'est bien un enregistrement périmé.
  2. Cherchez BFR Chantier dans les applications du téléphone et désinstallez-la si elle existe — l'application ne s'étant jamais ouverte, aucune donnée n'y est perdue.
  3. N'utilisez jamais « Effacer les données du site » dans Chrome pour ce domaine : BFR SAV partage la même origine, et vous effaceriez ses chantiers et ses rapports en même temps.
  4. Rouvrez l'application, puis installez-la à nouveau. Si le message persiste, il faut changer l'identifiant du manifeste (§ 7 de PUBLIER-SUR-GITHUB.md) : Chrome considère alors une application neuve.

Autres cas

  1. Ouvrez le menu de Chrome : s'il propose Ouvrir l'application au lieu d'Installer l'application, Chrome croit l'application installée.
  2. Cherchez l'icône sur l'écran d'accueil et dans le tiroir d'applications du téléphone.
  3. Réglages (Android) → Applications : cherchez BFR Chantier et BFR SAV. Une entrée en double explique le message.
  4. Avant de désinstaller quoi que ce soit : ouvrez chaque application et faites Menu → Exporter la sauvegarde — la désinstallation efface les données du téléphone.
  5. Si Chrome reste bloqué, installez depuis un autre navigateur (Edge, Samsung Internet) : chacun gère ses propres installations. L'application reste identique, hors connexion comprise.
